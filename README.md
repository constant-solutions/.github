# .github

Organization-wide defaults for **Constant Solutions LLC** ([constant.solutions](https://constant.solutions)). Files here apply to every repository in the org that doesn't define its own.

| Path | Purpose |
| --- | --- |
| `profile/README.md` | Organization profile shown on github.com/constant-solutions |
| `CODE_OF_CONDUCT.md` | Community standards |
| `CONTRIBUTING.md` | How to contribute |
| `SECURITY.md` | How to report vulnerabilities |
| `SUPPORT.md` | Where to get help |
| `GOVERNANCE.md` | How decisions are made |
| `CODEOWNERS` | Default reviewers for this repo |
| `ISSUE_TEMPLATE/` | Default issue forms and config |
| `PULL_REQUEST_TEMPLATE.md` | Default PR template |
| `FUNDING.yml` | Sponsorship links (placeholder) |
| `workflow-templates/` | Starter workflows offered to org repos |
| `.github/workflows/` | CI for this repository |
| `.github/dependabot.yml` | Dependency updates for workflows |

Note: GitHub only applies defaults from a **public** repository named `.github`. Defaults don't override a file a repo already has, and `.github/workflows` and `CODEOWNERS` here are not inherited.
