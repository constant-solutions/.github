# Security Policy

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public issues, discussions, or pull requests.

Instead, use GitHub's private vulnerability reporting: open the affected repository's **Security** tab and choose **Report a vulnerability**. If that isn't available, email **hello@constant.solutions** with "Security" in the subject line.

Include as much of the following as you can:

- Type of issue and affected component
- Steps to reproduce, or a proof of concept
- Impact and potential exploitation

## What to expect

- Acknowledgement within 3 business days
- An initial assessment within 10 business days
- Updates as we work toward a fix, and credit in the advisory if you wish

## Supported Versions

Unless a repository states otherwise, only the latest release and the default branch receive security fixes.
